\begin{abstract}
本文围绕竖直平面内轮腿机器人的姿态与运动控制问题展开研究。
题目给定机器人躯干质量为 $50$ kg，大腿和小腿长度均为 $0.5$ m，轮半径为 $0.1$ m，
机器人可控制轮毂、膝关节和髋关节三路驱动力矩。控制目标是在 $0\sim5$ m/s 速度范围内跟踪速度指令，
同时抵抗不平整地面与作用于躯干质心处的水平扰动力，并尽量保持髋部绝对高度和躯干姿态稳定。

为了在统一条件下比较不同控制思想，本文基于现有代码实现了一套轻量级二维仿真平台，
包含地形建模、逆运动学、简化动力学、四阶 Runge--Kutta 数值积分、失稳判据、日志记录、指标统计和曲线绘制。
控制算法按照由模型驱动到数据驱动的顺序展开：首先实现局部线性化 LQR；
然后实现带显式动力学、接触力、摩擦锥、执行器边界和预测安全约束的 WBC/QP 控制器；
最后实现 PPO 强化学习控制器，并进一步实现残差力矩控制和直接力矩控制两种方法。

本文实验覆盖八类固定测试场景和五种控制器，共计 $40$ 次仿真。正式评估默认不向控制器直接提供真实外力值，
使各方法在统一的盲扰动条件下比较。实验结果表明：四类控制器均完成全部八个场景；
LQR 结构简单，但在持续外力与 $5$ m/s 边界工况下速度偏差较大；
显式约束降阶 WBC/QP 的平均高度 RMSE 为 $3.80\times10^{-4}$ m，平均姿态 RMSE 为 $0.0095^\circ$，
在高度与姿态稳定性上表现最稳定，但速度跟踪并非最优；直接力矩 PPO 的平均速度 RMSE 最低，为 $0.0816$ m/s，
但在高速复合边界场景中的姿态误差明显增大；残差 PPO 能够稳定完成任务，但性能受到基础稳定器结构限制。
\end{abstract}

\section{题目重述与研究路线}

\subsection{题目要求}

研究对象为竖直平面内运动的轮腿机器人。机器人可控制轮的驱动力矩、膝关节驱动力矩和髋关节驱动力矩，并受到两类外部干扰：

\begin{enumerate}
    \item 不平整地面导致轮心高度、地面坡度和地形曲率变化；
    \item 作用于躯干质心处的水平外力，幅值不大于 $100$ N。
\end{enumerate}

设计目标是在 $0\sim5$ m/s 速度范围内稳定跟踪速度指令，使躯干尽量保持竖直，同时减小髋部绝对高度变化。

\section{二维仿真模型}

\subsection{模型边界}

模型保留了与控制任务直接相关的量：髋部水平位置、髋部高度、躯干倾角、三个方向速度、轮地摩擦限制、腿部伸缩能力、地形高度、坡度、曲率和水平外力。它适合用于比较控制策略，但不应等同于实机控制器验证平台。模型没有显式模拟轮转角、腿段质量分布、关节柔性、传感器延迟、轮地碰撞和复杂离地过程。

\subsection{状态、输入与地形}

仿真状态定义为
\begin{equation}
    \boldsymbol{x}
    =
    [x,\; y,\; \theta,\; v_x,\; v_y,\; \omega]^\mathsf{T},
\end{equation}
其中 $x,y$ 为髋部位置，$\theta$ 为躯干倾角，$v_x,v_y$ 为平动速度，$\omega$ 为躯干角速度。控制输入为
\begin{equation}
    \boldsymbol{\tau}
    =
    [\tau_{\mathrm{wheel}},\; \tau_{\mathrm{knee}},\; \tau_{\mathrm{hip}}]^\mathsf{T}.
\end{equation}

地形类位于 \code{src/model/terrain.py}，实现了四种地面：

\begin{itemize}
    \item \code{FlatTerrain}：平坦地面；
    \item \code{SineTerrain}：单一正弦地面；
    \item \code{MultiSineTerrain}：多频正弦叠加地面，并限制最大绝对高度；
    \item \code{NoiseTerrain}：随机采样后经过卷积平滑，并使用三次样条连续插值的伪随机地形。
\end{itemize}

地形向控制器和动力学模块提供高度 $h(x)$、坡度 $h'(x)$ 和曲率 $h''(x)$。其中正弦与多正弦地形使用解析导数，噪声地形使用三次样条的一阶和二阶导数。这样可以避免分段线性插值在节点附近产生不真实的曲率尖峰。

\subsection{运动学近似}

轮心高度由地形和轮半径确定：
\begin{equation}
    y_{\mathrm{wheel}} = h(x) + r.
\end{equation}

当前模型将腿部视为竖直方向上的等效伸缩机构，因此腿长为
\begin{equation}
    l = y - y_{\mathrm{wheel}}.
\end{equation}

在 \code{src/model/kinematics.py} 中，程序进一步根据两段等长连杆进行逆运动学计算。设大腿和小腿长度分别为 $L_1$、$L_2$，则膝关节内部夹角满足
\begin{equation}
    \cos \beta_{\mathrm{int}}
    =
    \frac{L_1^2 + L_2^2 - l^2}{2L_1L_2}.
\end{equation}
代码将其转换为膝关节屈曲角，并取髋关节角为膝关节屈曲角的一半。逆解主要用于判断腿长是否可达，以及构造 RL 观测量。

\subsection{简化动力学}

动力学实现位于 \code{src/model/dynamics.py}。所有控制器输出首先被裁剪到统一力矩上限：
\begin{equation}
    \boldsymbol{\tau}
    \leftarrow
    \operatorname{clip}(\boldsymbol{\tau},-\boldsymbol{\tau}_{\max},
    \boldsymbol{\tau}_{\max}).
\end{equation}

腿长变化率近似为
\begin{equation}
    \dot l = v_y-h'(x)v_x.
\end{equation}
膝关节和髋关节力矩共同产生主动腿部支撑力，被动弹簧阻尼元件提供附加支撑：
\begin{equation}
    F_{\mathrm{leg,act}}
    =
    \frac{\tau_{\mathrm{knee}} + 0.6\tau_{\mathrm{hip}}}{d},
    \qquad
    d = 0.25 \text{ m}.
\end{equation}
\begin{equation}
    F_{\mathrm{leg,pass}}
    =
    k_l(l_0-l)-c_l\dot l,
    \qquad
    F_{\mathrm{leg}}
    =
    F_{\mathrm{leg,act}}+F_{\mathrm{leg,pass}}.
\end{equation}

轮毂力矩映射为期望切向驱动力：
\begin{equation}
    F_{\mathrm{drive,cmd}}
    =
    \frac{\tau_{\mathrm{wheel}}}{r}.
\end{equation}

模型中的法向力和切向力为
\begin{align}
    F_n &= \max(F_{\mathrm{leg}},0), \\
    F_t &= \operatorname{clip}
    \left(
    F_{\mathrm{drive,cmd}},
    -\mu \max(F_n,1),
    \mu \max(F_n,1)
    \right).
\end{align}

三个方向的等效加速度分别写为
\begin{align}
    \ddot{x}
    &=
    \frac{
    F_t + F_{\mathrm{ext}}
    - c_x v_x
    - mg h'(x)
    }{m}, \\
    \ddot{y}
    &=
    \frac{
    F_{\mathrm{leg}} - mg - c_y v_y
    }{m}, \\
    \ddot{\theta}
    &=
    \frac{
    \tau_{\mathrm{hip}}
    + 0.15\tau_{\mathrm{knee}}
    + d_tF_t
    - k_\theta\theta
    - c_\theta\omega
    }{I}.
\end{align}

其中
\begin{equation}
    d_t=\gamma\max(y-h(x),0.1).
\end{equation}
这里，地形通过轮心高度、腿长、腿长变化率、坡度阻力和控制器预瞄共同影响运动。水平外力按题意作用于躯干质心，因此只进入水平平动方程，不直接形成俯仰力矩；俯仰扰动来自轮地切向接触力经等效耦合力臂 $d_t$ 的传递。程序使用四阶 Runge--Kutta 方法积分状态，因此每一个控制周期都要进行四次状态导数计算。积分后，日志记录与失败检测均使用推进后的新状态。

\subsection{失败判据}

仿真在每个时间步更新状态后立即检查安全条件。当前代码使用以下判据：

\begin{enumerate}
    \item 躯干倾角超过 $30^\circ$，记为 \code{theta_fail}；
    \item 髋部高度偏离 $y_{\mathrm{ref}}$ 超过 $0.15$ m，记为 \code{height_fail}；
    \item 腿长超出逆运动学可达范围，记为 \code{leg_infeasible}；
    \item 腿长小于 $0.18$ m，记为 \code{leg_collapsed}。
\end{enumerate}

固定场景默认在首次失败后终止仿真。命令行参数 \code{--continue-after-failure} 可以让程序继续记录失稳后的曲线。

\section{方法一：局部线性化 LQR 控制}

\subsection{方法思路}

LQR 的基本思想是：在给定速度附近寻找平衡状态，对非线性动力学进行局部线性化，然后使用二次型性能指标求解最优状态反馈增益。它结构清晰、计算量小，适合作为模型控制基线。

对于目标速度 $v_{\mathrm{cmd}}$，代码首先构造平衡状态
\begin{equation}
    \boldsymbol{x}_0
    =
    [0,\;y_{\mathrm{ref}},\;0,\;v_{\mathrm{cmd}},\;0,\;0]^\mathsf{T}.
\end{equation}

对应的近似平衡力矩需要同时抵消水平阻尼、重力和切向接触力引起的俯仰耦合：
\begin{align}
    \tau_{\mathrm{wheel},0}
    &= c_x v_{\mathrm{cmd}}r, \\
    \tau_{\mathrm{knee},0}+0.6\tau_{\mathrm{hip},0}
    &= dmg, \\
    0.15\tau_{\mathrm{knee},0}+\tau_{\mathrm{hip},0}
    &= -d_t c_xv_{\mathrm{cmd}}.
\end{align}

\subsection{数值线性化与反馈增益}

\code{src/controllers/lqr.py} 使用中心差分对状态方程进行数值线性化：
\begin{equation}
    \Delta\dot{\boldsymbol{x}}
    =
    A\Delta\boldsymbol{x}
    +
    B\Delta\boldsymbol{\tau}.
\end{equation}

差分步长为 $10^{-5}$。线性化过程在平地、无外力条件下进行。状态权重和输入权重分别为
\begin{align}
    Q
    &=
    \operatorname{diag}
    (0,\;600,\;1800,\;30,\;120,\;280), \\
    R
    &=
    \operatorname{diag}
    (0.03,\;0.06,\;0.05).
\end{align}

程序通过连续时间代数 Riccati 方程求解反馈矩阵 $K$，控制律为
\begin{equation}
    \boldsymbol{\tau}
    =
    \operatorname{clip}
    \left[
    \boldsymbol{\tau}_0
    -
    K(\boldsymbol{x}-\boldsymbol{x}_{\mathrm{ref}})
    \right].
\end{equation}

参考状态中的水平位置直接取当前 $x$，因此 LQR 只调节速度而不约束绝对行驶距离。不同目标速度的增益按照保留两位小数后的速度键缓存，避免每个时间步重复求解 Riccati 方程。

\subsection{实现特点与预期局限}

LQR 的优点是控制过程平滑、计算量小，并且容易解释。但它的线性化模型不显式感知当前地形，也没有外力观测器或积分环节。因此：

\begin{itemize}
    \item 对持续外力容易产生高度与姿态稳态偏差；
    \item 对较大地形曲率只能依靠状态反馈被动修正；
    \item 当状态显著偏离平衡点时，局部线性化假设逐渐失效。
\end{itemize}

\section{方法二：显式约束降阶 WBC/QP 控制}

\subsection{实现层级与决策变量}

理论上的全身控制通常在广义坐标空间中，以关节加速度、接触力和关节力矩作为决策变量，并显式加入系统动力学、接触约束、摩擦锥、执行器边界和关节可达范围。本文的机器人模型已经通过竖直腿长和轮地几何关系消去了部分关节坐标，因此 WBC/QP 采用与当前轻量级模型一致的降阶形式。与仅在三路力矩上做非线性搜索的简化版本不同，当前实现显式求解加速度、接触力、执行器力矩和安全松弛量：

\begin{equation}
    \boldsymbol{z}
    =
    [
    a_x,\;
    a_y,\;
    \alpha,\;
    F_t,\;
    F_n,\;
    \tau_{\mathrm{wheel}},\;
    \tau_{\mathrm{knee}},\;
    \tau_{\mathrm{hip}},\;
    s_{l,-},\;
    s_{l,+},\;
    s_{y,-},\;
    s_{y,+}
    ]^\mathsf{T}.
\end{equation}

其中 $F_t$ 和 $F_n$ 分别为轮地切向力与法向力；$s_{l,-},s_{l,+}$ 用于腿长预测边界；$s_{y,-},s_{y,+}$ 用于髋部绝对高度预测边界。四个松弛变量均满足非负约束，并在目标函数中受到较大惩罚。这样可以避免极端工况下 QP 完全不可行，同时用松弛量直接衡量安全裕度不足的程度。

\subsection{任务空间目标}

\code{src/controllers/wbc_qp.py} 根据当前状态构造期望任务空间加速度：
\begin{align}
    a_{x,\mathrm{des}}
    &=
    5.0(v_{\mathrm{cmd}}-v_x)
    +2.0e_{v,I}, \\
    a_{y,\mathrm{des}}
    &=
    115.0(y_{\mathrm{ref}}-y)
    -24.0v_y, \\
    \alpha_{\mathrm{des}}
    &=
    -125.0\theta-24.0\omega.
\end{align}
其中速度积分状态按
\begin{equation}
    e_{v,I}
    \leftarrow
    \operatorname{clip}
    \left[
    e_{v,I}+\Delta t(v_{\mathrm{cmd}}-v_x),-2,2
    \right]
\end{equation}
更新，用于减小持续扰动下的速度静差。

这三个目标分别对应速度跟踪、绝对高度保持和躯干竖直。竖直方向和姿态方向的权重大于水平方向，因为运输任务首先要求平台稳定，其次才是速度响应。

\subsection{动力学等式约束}

函数 \code{wbc_affine_dynamics()} 位于 \code{src/model/dynamics.py}。它为每个控制周期构造与前向仿真一致的仿射动力学方程。对于固定的当前状态和地形，QP 中的五组等式约束为
\begin{align}
    ma_x - F_t
    &=
    \hat F_{\mathrm{ext}} - c_xv_x - mgh'(x), \\
    ma_y - F_n
    &=
    -mg-c_yv_y, \\
    I\alpha-d_tF_t-0.15\tau_{\mathrm{knee}}-\tau_{\mathrm{hip}}
    &=
    -k_\theta\theta-c_\theta\omega, \\
    \tau_{\mathrm{wheel}}-rF_t
    &=0, \\
    \tau_{\mathrm{knee}}+0.6\tau_{\mathrm{hip}}-dF_n
    &=-dF_{\mathrm{leg,pass}}.
\end{align}

前两式是髋部平动动力学，第三式是躯干俯仰动力学，第四式将轮毂力矩映射为切向接触力，第五式将主动关节力矩和被动腿部支撑统一映射为总法向力。由于轮心高度已经通过 $y_{\mathrm{wheel}}=h(x)+r$ 解析消元，轮地法向几何约束不再作为额外决策方程出现。

\subsection{外力测量假设与公平评估}

符号 $\hat F_{\mathrm{ext}}$ 表示控制器可用的外力估计值，而不是仿真中施加的真实外力。正式对比命令默认令 $\hat F_{\mathrm{ext}}=0$，真实外力仍进入前向动力学，但不会直接送给任何控制器。这样可以避免 WBC/QP 或残差基线获得 LQR 与直接 PPO 没有使用的额外信息。若实际系统已经安装力传感器或外力观测器，可以通过命令行参数 \code{--provide-force-measurement} 单独评估带测量值的情况。

\subsection{接触、摩擦与执行器硬约束}

轮腿机器人在本文任务中应保持持续滚动接触。单纯使用 $F_n\ge0$ 会允许优化器主动选择卸载轮子的解；虽然这种解在单边接触数学上成立，但不符合持续行驶工况。因此程序使用
\begin{align}
    F_n &\ge 0.35mg, \\
    -\mu F_n \le F_t &\le \mu F_n.
\end{align}

第一式保持轮地接触，第二式为线性化库仑摩擦锥。执行器约束为
\begin{equation}
    -\boldsymbol{\tau}_{\max}
    \le
    \boldsymbol{\tau}
    \le
    \boldsymbol{\tau}_{\max}.
\end{equation}

这些条件都是 QP 的硬约束，而不是仿真结束后的裁剪或目标函数中的软惩罚。前向动力学仍保留力矩和摩擦裁剪，作为数值安全保护；在 QP 正常可行时，保护层不应改变控制器输出。

\subsection{地形预瞄与预测安全约束}

为了避免控制器只追求当前时刻的局部最优，程序使用 $T_p=0.30$ s 的短时预瞄。先沿当前速度估计未来水平位置
\begin{equation}
    x_p = x + T_pv_x,
\end{equation}
再查询未来地形高度 $h(x_p)$ 和坡度 $h'(x_p)$。未来腿长在当前加速度附近的一阶近似为
\begin{equation}
    l_p
    \approx
    y + T_pv_y + \frac{1}{2}T_p^2a_y
    -
    h(x_p)
    -
    \frac{1}{2}T_p^2h'(x_p)a_x
    -r.
\end{equation}

未来髋部高度为
\begin{equation}
    y_p
    \approx
    y+T_pv_y+\frac{1}{2}T_p^2a_y.
\end{equation}

QP 对 $l_p$ 和 $y_p$ 设置上下界，并允许使用高代价松弛变量。预瞄地形后再线性化，比直接使用当前点曲率做长时外推更稳定，尤其适合噪声地形和多频叠加地形。

\subsection{二次型目标函数}

完整目标函数写为
\begin{align}
    \min_{\boldsymbol{z}}\quad
    &
    \frac{1}{2}
    \left\|
    \boldsymbol{a}
    -
    \boldsymbol{a}_{\mathrm{des}}
    \right\|_{W_a}^2
    +
    \frac{w_\tau}{2}
    \left\|
    \frac{\boldsymbol{\tau}}
    {\boldsymbol{\tau}_{\max}}
    \right\|_2^2
    \nonumber\\
    &+
    \frac{w_{\Delta\tau}}{2}
    \left\|
    \frac{\boldsymbol{\tau}-\boldsymbol{\tau}_{\mathrm{last}}}
    {\boldsymbol{\tau}_{\max}}
    \right\|_2^2
    +
    \frac{w_f}{2}
    \left\|
    \frac{\boldsymbol{F}-\boldsymbol{F}_{\mathrm{nom}}}
    {\boldsymbol{F}_{\mathrm{scale}}}
    \right\|_2^2
    \nonumber\\
    &+
    \frac{w_l}{2}(s_{l,-}^2+s_{l,+}^2)
    +
    \frac{w_y}{2}(s_{y,-}^2+s_{y,+}^2),
\end{align}
其中
\begin{equation}
    W_a
    =
    \operatorname{diag}(8,\;180,\;120).
\end{equation}

当前实现取 $w_\tau=0.03$、$w_{\Delta\tau}=0.12$、$w_f=0.002$、$w_l=4\times10^5$、$w_y=6\times10^5$。程序将该问题装配为标准凸二次规划
\[
    \min_z \frac{1}{2} z^\mathsf{T} P z + q^\mathsf{T} z,
    \qquad
    l \le A z \le u,
\]
并使用 OSQP 专用 QP 求解器求解。等式约束、不等式约束和变量上下界统一进入矩阵 $A$，从而避免把 QP 交给通用非线性 SLSQP 数值优化器。若候选解的等式残差、线性不等式残差或数值有效性不满足要求，则回退到重新计算的稳定基线，而不是沿用已经恶化的上一时刻力矩。

\subsection{诊断信息}

仿真日志新增了 QP 可行解比例、OSQP 求解成功比例、回退比例、迭代次数、求解耗时、原始残差、对偶残差、最大等式残差、最大不等式残差、摩擦利用率、腿长松弛量、高度松弛量、预测腿长和预测高度。对于 WBC/QP，\code{scripts/run_compare.py} 还会额外生成文件名以 \code{__diagnostics.png} 结尾的约束诊断图。

\section{方法三：PPO 强化学习控制}

\subsection{Gymnasium 环境}

强化学习环境实现于 \code{src/rl/env.py}，符合 Gymnasium 接口。动作空间为
\begin{equation}
    \boldsymbol{a}\in[-1,1]^3.
\end{equation}

观测向量为
\begin{equation}
    \boldsymbol{o}
    =
    [
    y-y_{\mathrm{ref}},
    \theta,
    v_x-v_{\mathrm{cmd}},
    v_y,
    \omega,
    l,
    h(x),
    h'(x),
    v_{\mathrm{cmd}}
    ]^\mathsf{T}.
\end{equation}

观测中包含高度误差、姿态、速度误差、腿长、地形高度、坡度和目标速度。与 LQR 相比，策略网络可以直接利用地形信息形成非线性映射。

每次环境重置时，程序会在期望初始状态附近加入小幅随机扰动，包括髋部高度、躯干角度、水平速度、竖直速度和角速度。这样可以避免策略只在完全静止的理想初值附近工作。

\subsection{奖励函数}

每一步奖励为
\begin{align}
    r ={}&
    0.5
    +3.5\exp[-130(y-y_{\mathrm{ref}})^2]
    +2.5\exp(-45\theta^2) \nonumber\\
    &+1.2\exp[-0.7(v_x-v_{\mathrm{cmd}})^2]
    -35(y-y_{\mathrm{ref}})^2
    -3\theta^2 \nonumber\\
    &-c_a\|\boldsymbol{a}\|_2^2
    -0.001\|\boldsymbol{a}_{\mathrm{dyn}}\|_2^2
    +r_{\mathrm{sat}}
    +r_{\mathrm{fail}},
\end{align}
其中 $\boldsymbol{a}_{\mathrm{dyn}}=[\ddot{x},\ddot{y},\ddot{\theta}]^\mathsf{T}$。动作代价系数在残差模式下为 $0.03$，在直接模式下为 $0.008$。当任一归一化动作接近边界时额外惩罚 $0.5$；触发失败条件时额外惩罚 $50$。

直接模式还加入了较小的力矩比例惩罚：
\begin{equation}
    -0.004
    \left\|
    \frac{\boldsymbol{\tau}}{\boldsymbol{\tau}_{\max}}
    \right\|_2^2.
\end{equation}

\subsection{残差力矩 PPO}

残差 PPO 不直接负责全部力矩，而是围绕一个基础稳定器学习修正量。基础稳定器位于 \code{src/controllers/base.py}。其水平、竖直和姿态控制分别为
\begin{align}
    a_{x,\mathrm{cmd}}
    &=
    3(v_{\mathrm{cmd}}-v_x)
    -
    \frac{\hat F_{\mathrm{ext}}}{m}, \\
    a_{y,\mathrm{cmd}}
    &=
    70(y_{\mathrm{ref}}-y)-16v_y, \\
    \alpha_{\mathrm{cmd}}
    &=
    -85\theta-18\omega.
\end{align}

对应的基础力矩经过重力补偿后，与策略修正量相加。若显式启用外力测量开关，基础稳定器还会使用 $\hat F_{\mathrm{ext}}$ 做前馈补偿；正式统一评估中该估计量为零。
\begin{equation}
    \boldsymbol{\tau}
    =
    \operatorname{clip}
    \left(
    \boldsymbol{\tau}_{\mathrm{base}}
    +
    \boldsymbol{a}\odot
    [5,25,25]^\mathsf{T}
    \right).
\end{equation}

残差控制的训练难度较低，因为策略不必从零学会支撑躯干，只需要修正基础控制器的不足。
\subsection{直接力矩 PPO}

直接 PPO 输出完整执行器力矩：
\begin{align}
    \tau_{\mathrm{wheel}}
    &= 30a_1, \\
    \tau_{\mathrm{knee}}
    &= \frac{a_2+1}{2}\cdot160, \\
    \tau_{\mathrm{hip}}
    &= 120a_3.
\end{align}

膝关节是主要腿部支撑执行器，因此代码将其映射到 $[0,160]$ N$\cdot$m，而不是对称的负正范围。直接模式更难训练，但它的控制上限更高：如果训练充分，策略不再受基础 PD 控制器结构限制。

直接 PPO 模型采用分阶段训练思路：先在平地简单任务中学会支撑和移动，再逐渐加入外力和随机地形。
\subsection{随机训练场景}

训练脚本 \code{scripts/train_rl.py} 支持三档随机场景：

\begin{itemize}
    \item \code{random_easy}：$0\sim2$ m/s，平地，无外力；
    \item \code{random_force}：$0\sim3$ m/s，平地，随机平滑脉冲或渐变外力；
    \item \code{random_full}：$0\sim5$ m/s，随机平地、正弦、多正弦或噪声地形，并随机加入平滑外力。
\end{itemize}

默认 PPO 超参数为：\code{MlpPolicy}、\code{n_steps=1024}、\code{batch_size=256}、$\gamma=0.99$、$\lambda_{\mathrm{GAE}}=0.95$、裁剪系数 $0.2$。残差模式学习率为 $2\times10^{-4}$，熵系数为 $0.003$；直接模式学习率为 $3\times10^{-4}$，熵系数为 $0.008$。

从总体结果可以得到四个结论。

\begin{enumerate}
    \item LQR 没有在复杂场景中立即失稳，但缺少积分和扰动估计时，高速与持续推力场景的速度误差较大。这说明“成功完成仿真”和“满足高稳定运输要求”不是一回事。
    \item 显式约束降阶 WBC/QP 在八个场景中均完成任务。全部场景的 QP 可行解比例与 OSQP 求解成功比例均为 $100\%$，回退比例为零；最大等式残差保持在 $3.13\times10^{-13}$ 以内，平均求解耗时约为 $0.102$ ms。它的优势主要体现在高度和姿态稳定性，速度 RMSE 并不是所有场景中最低。
    \item 前馈残差 PPO 去除了基础项中的速度、高度和姿态误差反馈，因而更接近“模型前馈 + PPO 反馈残差”的干净结构。它能够完成全部场景，但平均速度 RMSE 明显高于 PD 残差 PPO，说明相同训练预算下 PPO 需要承担更难的反馈稳定任务。
    \item 直接 PPO 的平均速度 RMSE 最低，但它并非所有指标上的最佳方法。在高速复合边界场景 G 中，其姿态 RMSE 达到 $4.06^\circ$；若强调平台稳定，WBC/QP 更合适。
\end{enumerate}

为避免 LQR 和各类 PPO 只出现在表格中，评估脚本还为每个场景生成五控制器叠加图。分场景鲁棒性分析中逐一展示 LQR、WBC/QP、残差 PPO、前馈残差 PPO 和直接 PPO 的高度误差、姿态角、速度和力矩范数。

\subsection{平顺性与能耗的补充观察}

从 \code{.npz} 日志重新计算可知，规则正弦地形 C1 中，WBC/QP 的平顺性指标约为 $142.45$，直接 PPO 为 $244.00$，而 LQR 和残差 PPO 分别达到 $4984.69$ 和 $4531.24$。这说明显式动力学约束和地形预瞄在规则地形中十分有效。

在更困难的组合压力场景 E 中，LQR 和残差 PPO 的平顺性指标分别约为 $52580.2$ 和 $44638.6$，直接 PPO 为 $3169.62$，WBC/QP 为 $5858.38$。在题目边界组合场景 G 中，WBC/QP 的该指标为 $4807.11$，仍明显低于 LQR 的 $45775.6$ 与残差 PPO 的 $39869.2$。这表明当前 QP 权重在满足约束的同时，也保持了较好的加速度连续性。

四类控制器的力矩平方积分整体处于相同量级。由于膝关节需要持续提供重力支撑，能耗代理量长期由膝关节力矩主导。若后续希望进行能耗优化，应建立更严格的电机功率模型，而不仅使用 $\int\|\tau\|^2\mathrm{d}t$。

\section{方法对比与工程讨论}

\subsection{LQR：适合作为清晰可靠的基线}

LQR 的最大价值是结构简单、可解释、易于调参。在平地、轻度扰动和平滑随机地形中，它可以取得稳定结果。持续推力和高速实验说明，缺少外力估计器和速度积分环节时，LQR 容易产生明显的速度静差。

如果继续改进 LQR，可以考虑：

\begin{itemize}
    \item 加入外力估计器和前馈补偿；
    \item 引入积分状态，构造 LQI 以减小稳态误差；
    \item 根据速度和地形状态进行增益调度；
    \item 使用模型预测控制处理力矩约束。
\end{itemize}

\subsection{WBC/QP：约束明确，适合作为模型控制主线}

显式约束降阶 WBC/QP 在全部固定场景中表现稳定，尤其适合直接表达“优先保持高度与姿态”的任务需求。相较仅在三路力矩上搜索的简化方案，当前实现将加速度、接触力、被动腿部支撑、执行器映射、摩擦锥和预测安全范围统一放入 QP。八个场景中的求解成功率均为 $100\%$，说明当前约束与参数设定匹配良好。需要强调的是，这一结论不代表 WBC/QP 在所有指标上最优；在高速和平地速度跟踪等场景中，直接 PPO 的速度误差更低。

当前实现仍有几个值得继续改进的地方：

\begin{itemize}
    \item 将降阶模型进一步扩展为显式关节坐标的多刚体动力学；
    \item 复用 OSQP 工作区和稀疏矩阵结构，进一步减少在线装配和初始化开销；
    \item 把当前单步预瞄扩展为短时域 MPC，同时优化多个未来控制周期；
    \item 为松弛量设置分层优先级，区分“可接受预瞄误差”和“必须立即处理的安全风险”；
    \item 对比 OSQP、qpOASES 等不同专用 QP 求解器在高频控制中的实时性和数值鲁棒性。
\end{itemize}

\subsection{残差 PPO：训练容易，性能上限受基础控制器影响}

残差 PPO 的优点是训练稳定。即使训练步数有限，策略也能依靠基础 PD 与重力补偿控制器保持机器人站立和运动。现有输出中，它成功完成全部八个固定场景。

但残差 PPO 的动作范围只有 $[5,25,25]^\mathsf{T}$ N$\cdot$m，策略只能在基础控制器附近做修正。当基础控制器在复杂地形中的速度和姿态响应并不理想时，残差策略的改进空间受到限制。这是残差 PPO 在多个场景中速度 RMSE 和姿态 RMSE 偏大的主要原因之一。

\subsection{直接 PPO：训练成本高，速度跟踪能力突出}

直接 PPO 不依赖固定 PD 基线，能够在整个力矩范围内学习更灵活的控制规律。在现有输出中，它在全部八个场景中保持成功，并取得最低的平均速度 RMSE。不过，规则地形和 $5$ m/s 边界场景中的姿态误差明显高于 WBC/QP，因此不能只根据速度指标判断控制质量。

它的代价也十分明确：

\begin{itemize}
    \item 训练难度显著高于残差模式，需要课程式训练和更多采样；
    \item 动作更活跃，部分场景下平顺性不如 WBC/QP；
    \item 策略性能依赖训练分布，面对真实系统参数偏差时仍需要系统辨识、域随机化和实机安全约束；
    \item 神经网络输出缺乏显式可解释约束，部署时应与安全过滤器或备用控制器结合。
\end{itemize}

\subsection{最佳控制器}

本项目没有一个脱离场景的绝对最佳控制器：

\begin{itemize}
    \item 若强调低计算量和可解释性，LQR 是合理基线；
    \item 若模型可信、地形可测且优先目标是平台高度与姿态稳定，WBC/QP 的姿态控制精度最高；
    \item 若希望较低训练难度并快速得到可用 RL 策略，残差 PPO 更稳妥；
    \item 若愿意承担更高训练成本，并且优先追求速度跟踪，直接 PPO 最有优势。
\end{itemize}

\section{总结}

本文基于当前仓库中的全部核心代码和重新生成的输出，对轮腿机器人姿态与运动控制问题进行了完整梳理。项目采用轻量级二维降阶模型，在统一地形、统一盲扰动条件、统一力矩限制和统一失败判据下，对 LQR、显式约束降阶 WBC/QP、残差 PPO 和直接 PPO 进行了对比。

实验结果表明：

\begin{enumerate}
    \item LQR 能够作为稳定、易解释的基线控制器，但面对持续外力时存在明显稳态偏差；
    \item 显式约束降阶 WBC/QP 在八类场景中均完成任务，平均高度和姿态误差最低；在题目边界组合场景中仍保持 $100\%$ 求解成功率；
    \item 残差 PPO 易于训练，能够稳定完成全部场景，但其性能上限受到基础稳定器结构限制；
    \item 直接 PPO 训练成本更高，但平均速度误差最低；在高速边界场景中仍需进一步抑制姿态波动。
\end{enumerate}

从课程作业角度看，这套代码已经形成了完整闭环：题目要求被转换为参数、场景、动力学、控制器、指标、日志和图像；理论方法也通过真实输出得到了可复核的比较。若进一步面向高保真仿真或实机部署，下一步应加入更完整的刚体动力学、显式接触约束、执行器模型、传感器噪声、参数随机化和安全控制屏障，并保存每次实验的模型哈希、运行命令和随机种子，以提高结果可追溯性。
